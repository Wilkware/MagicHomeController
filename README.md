Symcon Modulbibliothek für die Ansteuerung von WiFi LED Controllern der Firma _Magic Home_.

Folgende Module beinhaltet diese Bibliothek:

- __Magic Home Discovery__ ([Dokumentation](Magic%20Home%20Discovery))  
Gerätesuche für alle im Netzwerk befindlichen Magic Home Controller.

- __Magic Home Controller__ ([Dokumentation](Magic%20Home%20Controller))  
Modul zur Ansteuerung eines WiFi LED Controllers (Farbe, Helligkeit, Muster/Effekte) inkl. Kachel-Visualisierung.  
Eine Übersicht aller unterstützten Controller findet sich in der [Dokumentation](Magic%20Home%20Controller#user-content-1-funktionsumfang).
